# Notice

This repository contains reproducibility materials associated with a University of Bristol MSc dissertation.

The project builds on the public MSKA implementation by Guan et al.:

https://github.com/sutwangyan/MSKA

The complete upstream MSKA source tree is not redistributed in this public repository. The `patches/` directory records the dissertation-specific implementation changes against the retained working tree, while `configs/` and `analysis/` contain the final experimental configurations and dissertation-specific analysis scripts.

No dataset files, trained model checkpoints, access credentials or other restricted/large experimental artefacts are distributed here.

Users who wish to rerun the full training pipeline must obtain the upstream code and required datasets/checkpoints under the terms applicable to those resources.
